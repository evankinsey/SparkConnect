2. **Box Fill** — add a couple devices/conductors, show the total update.

4. **Pipe Bending** — enter an offset + angle, show the marks/shrink.
5. **Sparky** — type ONE real question ("What size THHN for a 50A circuit at 75°C?"), show the answer.
6. **Home/tools screen** — slow pan over the tool grid for the end card.
