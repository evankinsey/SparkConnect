## Day 2 — Sparky AI demo
**Format:** vertical 9:16, 20–28s. Mostly screen recording + a 2s talking-head hook.
**Feature:** Sparky chat. **CTA goal:** trial / try free.

### Hook (say + on screen)
> "I asked my phone an NEC question and got a straight answer."

### Script (numbered, ~25s)
1. **[TALKING HEAD]** "I asked my phone an NEC question — and got a straight answer." *(0–3s)*
2. **[SCREEN]** Open Sparky. Type a real one: "What size THHN for a 50A circuit at 75°C?" *(3–9s)*
3. **[SCREEN]** Answer appears — let it land, scroll once so it reads real. *(9–16s)*
4. **[TALKING HEAD/VO]** "Plain English. No digging through the code book on a ladder." *(16–21s)*
5. **[VO + end card]** "Three free answers a day. It's Sparky, in SparkConnect." *(21–25s)*

### Screen-recording shot list
1. Sparky home → tap the input.
2. Type the question (film the typing, it reads as authentic).
3. Send → answer renders; hold on the key line.
4. Scroll the answer once, then back to home grid.
> Use a real, defensible question. Don't stage an answer the app didn't produce.

2. **[SCREEN]** Open Conduit Fill → select ¾″ EMT. *(4–9s)*

4. **[SCREEN]** Reveal the fill %. Pause on it. *(15–20s)*
5. **[TALKING HEAD]** "Stop doing this in your head on the ladder." *(20–25s)*
